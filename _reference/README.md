# Referensi

Contoh solusi untuk dibandingkan **setelah** kamu mencoba sendiri.

- Folder diawali `_`, jadi dilewati oleh `go build ./...` dan `go test ./...`.
- Jalankan secara eksplisit: `go run ./_reference/01-bytes/byte-explorer "Hé🚀"`
- Jangan copy-paste ke folder project. Tulis versimu sendiri, lalu bandingkan.
